# Moodle Grader — technical notes

This is a standalone single-file HTML tool (`moodle_grader.html`) for grading Moodle assignment submissions locally in the browser. No server, no install.

## What it does

- Loads a folder containing student PDF submissions + a Moodle grading worksheet (CSV)
- Displays each PDF side-by-side with a grade/notes form
- Auto-saves progress to `localStorage`
- Exports a filled-in CSV ready to upload back to Moodle

## Two modes

**Normal mode (folder picker):** User clicks "בחר תיקייה" → picks a folder with PDFs + CSV → grades → exports CSV.

**Embedded mode:** A `data.js` file next to the HTML pre-populates everything (course name, student list, CSV data). The grader skips setup and goes straight to grading. Generated by `setup_moodle_grading.command`.

## Grading schemes

- **numeric** — free number input, configurable max grade
- **binary_0_100** — two big buttons: ✓ 100 / ✗ 0, keyboard `1`/`0`
- **pass_fail** — two big buttons: ✓ עבר / ✗ לא עבר, keyboard `P`/`F` or `1`/`0`

## Keyboard shortcuts (in grader view)

| Key | Action |
|---|---|
| `Enter` / `→` (RTL: left arrow) | Save & next |
| `←` (RTL: right arrow) | Previous |
| `Space` | Skip |
| `Cmd/Ctrl+Enter` | Save & next (works from text fields) |
| `1` / `P` | Quick-grade positive (100 / עבר) |
| `0` / `F` | Quick-grade negative (0 / לא עבר) |
| `S` | Switch PDF view to student submission |
| `Q` | Switch PDF view to exercise questions (if provided) |
| `A` | Switch PDF view to full solution (if provided) |
| `W` | Open solution/questions in a separate window |

## State / persistence

- Grades and notes are saved to `localStorage` (`moodleGraderState_v2`, plus `::course::assignment` in embedded mode so graders never share progress) after every keystroke (600ms debounce).
- Per-course preferences (scheme, max grade) saved to `localStorage` (`moodleGraderPrefs_v2`).
- Folder handle persisted via IndexedDB so the folder doesn't need to be re-picked on reload.
- "Resume" banner appears on load if a previous session exists.

## Export / pushing grades back

Two buttons:
- **"📤 ייצוא ל-Moodle"** — recommended. Copies a JSON payload (grade + note per student) to the clipboard for the **Moodle Push** bookmarklet (`moodle_push.html`), which fills quick-grading directly. See `moodle_grading_WORKFLOW.md`.
- **"ייצוא CSV ⬇"** — downloads a filled worksheet CSV. NOTE: Moodle's worksheet upload imports **feedback only** and silently drops pass/fail *scale* grades, so CSV is not reliable for grades — use the Push bookmarklet instead.

Pass/fail values are `עובר` / `לא עובר` (must match the Moodle scale exactly).

## Embedded mode (`data.js`)

If a `data.js` file exists next to the HTML, it is loaded automatically. It must set `window.__EMBEDDED_DATA` with this shape:

```js
window.__EMBEDDED_DATA = {
  course: "math_tools",          // "physics_a" | "math_tools" | "custom"
  assignmentName: "תרגיל 9",
  maxGrade: 100,
  gradingScheme: "binary_0_100", // optional, overrides course default
  csvHeader: [...],              // array of column name strings
  cols: { name, identifier, grade, feedback, submitDate, onlineText, status }, // column indices
  csvAllRows: [...],             // array of objects keyed by header
  students: [
    {
      name: "שם מלא",
      pdfFile: "filename.pdf",   // null if no PDF
      pdfFiles: ["a.pdf","b.pdf"], // optional, all PDFs (file switcher if >1)
      submitted: true,           // optional; submitted but no PDF => not auto-failed
      otherFiles: ["photo.jpg"], // optional, non-PDF file names
      hasExtension: false,       // optional; extension => never auto-failed
      gradeFromCsv: "",
      feedbackFromCsv: "",
      submitDate: "...",
      onlineText: "...",
    },
    ...
  ],
  auxFiles: {                    // optional
    questions: "questions.pdf",
    solution: "solution.pdf",
  },
  sectionLabel: "קבוצות 3–4",   // optional, shown as colored banner
  sectionOk: true,               // optional, false = red warning
};
```

## Key implementation notes for editing

- **No external dependencies** — pure vanilla JS + HTML + CSS, no npm, no bundler.
- **`normalizeName()`** strips whitespace and punctuation for fuzzy PDF↔student matching.
- **`saveCurrent()`** only writes grades if `s._interacted` is true (prevents marking-graded just by scrolling past a student).
- **RTL layout** — the side panel is on the right, PDF on the left. Arrow key directions are flipped (`ArrowLeft` = next, `ArrowRight` = prev).
- **`findCol()`** searches CSV headers case-insensitively and supports Hebrew/English variants.
- To add a new course: add an entry to `DEFAULT_SCHEMES` and a matching `<option>` in the `#course-select` dropdown.
